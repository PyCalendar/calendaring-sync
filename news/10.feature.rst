Added the CalDAV adapter, :class:`~calendaring_sync.adapters.caldav.CalDAVAdapter` and :class:`~calendaring_sync.adapters.caldav.AsyncCalDAVAdapter`, which syncs one calendar through python-caldav 3.6.0 or later; install it with the ``caldav`` extra. A calendar the server no longer has raises :exc:`~calendaring_sync.error.ScopeGoneError`, and a full listing the server cuts short raises :exc:`~calendaring_sync.error.IncompleteListingError`.
