Added the JMAP adapter, :class:`~calendaring_sync.adapters.jmap.JMAPAdapter` and :class:`~calendaring_sync.adapters.jmap.AsyncJMAPAdapter`, which syncs one account's calendar events through calendaring-jmap 2.0.0 or later; install it with the ``jmap`` extra. A create or change the server refuses because another event holds its uid becomes a conflict, including one Stalwart 1.0 refuses for an instance of that uid in the same calendar.
